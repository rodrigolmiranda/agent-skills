# Clarification and disposition

Use Interchange's [exchange contract](../../interchange/references/communication.md) for message fields, question states, startup and receipt mechanics.

Prepare the [semantic assignment](../templates/assignment.md) with settled scope, acceptance and explicit gates. Verify questions against evidence and answer within existing authority. Resolve material choices before plan approval; apply [supervisor technical decisions](../SKILL.md#supervisor-technical-decisions) before routing a question to the owner. Prefer configurable behavior when practical within approved scope; escalate when configurability itself materially expands cost or scope. Silence is not approval.

Record answers and packet revisions before releasing dependent work. Review against that accepted packet, issue bounded correction findings, then record acceptance disposition and reconcile GitHub. Recompute the safe ready set on each material exchange. Communication receipt is never product acceptance.

For a project explicitly adopting the portfolio browser policy, load its configured adapter; do not apply personal credential-routing preferences to unrelated adopters.
