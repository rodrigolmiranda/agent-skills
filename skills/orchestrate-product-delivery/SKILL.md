# Portfolio delivery compatibility entry point

Load the installed `delivery-orchestrator` skill. It owns discovery, knowledge intake, planning, GitHub breakdown, scheduling, acceptance coordination and continuation. Its `references/knowledge-and-discovery.md` preserves the knowledge and re-baselining paths formerly here. Read applicable portfolio governance for principles, authority and adoption. Interchange owns execution transport. This entry point adds no workflow, model default or permission.
