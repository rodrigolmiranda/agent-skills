# Exchange contract

Use [message templates](../templates/messages.md). Every exchange identifies project/job, packet revision, attempt, sender, recipient and durable record. Native and external sessions use the same record contract with their supported transports.

1. Read the supplied assignment, verify baseline and ownership, and write a startup receipt naming understood scope and material questions.
2. If authorized and clear, report all clear and actual local start time with UTC offset/timezone, then proceed without waiting for acknowledgement. Otherwise hold dependent actions only; continue safe authorized independent work.
3. Write questions before notification. Include evidence, precise gap, options when meaningful, recommendation, blocked actions and decision owner. States are open → needs evidence (optional) → answered → incorporated. Record answer provenance, timestamp and resulting packet revision; preserve identifiable answer history. Only the authorized decision owner supplies the answer. Route worker engineering questions to the assignment supervisor; a question is not automatically a request for human approval. The supplied authority determines which decisions that supervisor can resolve.
4. On resume, read the recorded answers, acknowledge incorporation and proceed within the released scope. A new external invocation receives a new attempt ID even when it reuses a provider session.
5. Return a durable handover with exact artifact/head, checks, unresolved gaps, resources and next owner. Notify using the supported route. Registered callbacks require attempt and artifact verification before acknowledgement; manual reports remain labelled reports, not fabricated callbacks.

A worker does not hold a model open to poll. Record its idle/exit state and the supervisor responsible for the next notification. Queue acceptance, actual receipt and accepted outcome are separate facts. Repeated notifications are deduplicated by event ID. Questions and answers cannot live only in chat; transcribe a direct human answer with its actual source.
