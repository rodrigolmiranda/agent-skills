# Authorized profile resolution

Semantic role selection belongs to the assignment owner. Receive the explicitly selected role/profile; do not independently choose a different model or scope.

Resolve the explicitly authorized provider/model/effort through the supported adapter. Pin each attempt and record requested versus observed identity. The example profile is a schema, not live availability or fallback authority. Provider exhaustion and rejected settings return to the coordinator; preserve evidence and do not silently switch provider, family, billing pool or effort. Per-request choices override adopted project then user profiles. A relay transports events, not shared context.
